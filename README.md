# 🔥❄️ 森林冰火人 — 布布 & 一二

一款基于 HTML5 Canvas 的经典双人协作平台跳跃游戏，以原创IP角色「**布布**」和「**一二**」为主角。

![Game Preview](screenshot.png)

## 🎮 游戏简介

《森林冰火人》复刻经典的双人协作解谜玩法。玩家需要同时操控两个角色，利用各自元素特性，收集宝石、躲避陷阱、到达出口。

### 角色介绍

| 角色 | 元素 | 原型 | 操作 | 特性 |
|------|------|------|------|------|
| 🐼 **一二** | 水/冰 | 白色熊猫 | W/A/S/D | 可穿越水域，害怕岩浆 🔥 |
| 🐻 **布布** | 火 | 棕色熊 | ↑/←/↓/→ | 可穿越岩浆，害怕水域 💧 |

- 💀 **绿色酸液**对两个角色都有伤害
- 💎 **蓝色宝石**由一二收集，**红色宝石**由布布收集
- 🚪 两个角色都需到达各自的传送门才能通关

### 关卡

| 关卡 | 名称 | 特色 |
|------|------|------|
| 第1关 | 森林初遇 | 教程关卡，学习基础操作 |
| 第2关 | 交错之路 | 推箱子、拉杆与门 |
| 第3关 | 潮汐上升 | 移动平台、酸液陷阱 |
| 第4关 | 分室迷局 | 角色分路、平行解谜 |
| 第5关 | 最终试炼 | 全部机制综合挑战 |

## 🕹️ 操作说明

### 键盘操作（推荐）
- **一二**: `W`跳跃 `A`左移 `D`右移 `S`下移
- **布布**: `↑`跳跃 `←`左移 `→`右移 `↓`下移
- **通用**: `R`重新开始 `ESC`暂停/菜单

### 移动端操作
- 屏幕左半区域为**一二**的虚拟摇杆
- 屏幕右半区域为**布布**的虚拟摇杆

## 🚀 运行方式

1. 直接用浏览器打开 `index.html` 文件
2. 或部署到任意静态服务器
3. 支持所有现代浏览器（Chrome、Firefox、Safari、Edge）

## 🛠️ 技术栈

- HTML5 Canvas
- 原生 JavaScript (ES6+)
- Web Audio API (音效)
- localStorage (存档)
- 响应式设计 (支持桌面和移动端)
